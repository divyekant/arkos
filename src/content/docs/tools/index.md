# The Arkos Ecosystem

Arkos is a collection of specialized dev tools that handle everything around code — testing, documentation, memory, orchestration, project management — so AI coding agents focus on writing code and developers focus on shipping.

## Infrastructure

The foundation layer. These tools store, index, and orchestrate.

- **[Memories](/tools/memories/)** — Self-hosted semantic memory with graph-aware search, temporal reasoning, multi-backend routing, hybrid search, and 12-hook Claude Code integration
- **[Carto](/tools/carto/)** — Codebase intelligence with 15-command CLI and web dashboard
- **[SwarmEngine](/tools/swarm-engine/)** — Multi-agent DAG orchestration
- **[Deck](/tools/deck/)** — Local-first dashboard for Claude Code and Codex sessions and cost
- **[Relay](/tools/relay/)** — Peer-to-peer messaging between Claude Code and Codex sessions, with no hub and no cloud

## Orchestration

Systems that run agent-led builds and measure them.

- **[Olympus](/tools/olympus/)** — Markdown-only build system with a fixed orchestration graph and sixteen roles
- **[Crew](/tools/crew/)** — Multi-model build orchestrator: the session model leads, other models build
- **[Metron](/tools/metron/)** — Token metering per PR, with an attribution ledger and billing reconciliation
- **[codex-cu](/tools/codex-cu/)** — The Codex computer-use runtime, available inside Claude Code

## Dev Workflow

Skills that plug into your coding workflow via Claude Code, Cursor, or Codex.

- **[Conductor](/tools/conductor/)** — Skill orchestration and pipelines
- **[Apollo](/tools/apollo/)** — Project governance and conventions
- **[Delphi](/tools/delphi/)** — Test scenario generation and execution
- **[Hermes](/tools/hermes/)** — Audience-specific documentation
- **[Argos](/tools/argos/)** — Zero-cost issue guardian with policy-governed autonomy and 5-level confidence system
- **[Learning](/tools/learning-skill/)** — Failure capture and cross-session learning
- **[Kalos](/tools/kalos/)** — Design governance and token enforcement
- **[Pencil Prototyping](/tools/pencil-prototyping/)** — Visual design prototyping powered by [Pencil.dev](https://pencil.dev)
- **[Resilience](/tools/resilience/)** — Failure containment for systems where failures cross component boundaries
- **[UI-Val](/tools/ui-val/)** — Visual UI validation across desktop, tablet, and mobile viewports
- **[Deep Research](/tools/deep-research/)** — Parallel web research with query variance and cited findings
- **[Think Different](/tools/think-different/)** — On-demand lateral thinking when straight-line solving stalls

## Agent Frameworks

Building blocks for multi-agent systems.

- **[PersonaSmith](/tools/persona-smith/)** — 75 research-backed AI agent personas

## Utilities

Cross-cutting capabilities used by other tools.

- **[Pheme](/tools/pheme/)** — Universal agent-to-human notifications across 100+ channels, powered by [Apprise](https://github.com/caronc/apprise)
